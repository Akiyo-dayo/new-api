# 排行榜时间范围模式设计

## 目标

排行榜默认恢复原仓的滚动窗口，同时允许每位用户在本地切换到自然周期。个人模式选择不写入服务端全局配置，也不影响其他用户。

## 行为

- `rolling` 为默认模式：今天/本周/本月/今年分别使用最近 24 小时、7×24 小时、30×24 小时、365×24 小时。
- `natural` 使用 Asia/Shanghai 自然周期算法：当日、周一、月初、年初作为起点。
- API 接收可选 `mode=rolling|natural`；缺省或非法值回退 `rolling`。
- 排行榜和 Root 用户消费统计使用同一个模式。
- 服务端缓存键同时包含周期和模式，避免两种结果串缓存。

## 前端交互

- 在“今天 / 本周 / 本月 / 今年”后增加“滚动窗口 / 自然周期”切换。
- 当前模式同步到 `/rankings?period=...&mode=...`。
- 浏览器 `localStorage` 保存个人模式；没有 URL 模式时使用本地保存值，默认 `rolling`。

## 验收

- 后端周期边界测试覆盖两种模式、非法模式回退和缓存键隔离。
- 前端类型检查和生产构建通过。
- 本地页面可切换两种模式并触发对应 API 请求。
- 不执行线上部署，不操作生产容器或数据库。
